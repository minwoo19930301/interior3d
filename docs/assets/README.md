# Reference collection

19 locally authored GLB models, generated through a real project-local Blender MCP connection to Blender 4.5.11 LTS. Models use metres, Y-up, front +Z, bottom-centre origin. The editable master and generation evidence are retained with the task artifacts; runtime models and self-rendered thumbnails are in `public/models` and `public/thumbnails`.

Before publication, the 19 thumbnail PNGs had Blender's textual export metadata removed. Compressed image data, dimensions, alpha and color-management chunks remained byte-identical; no visual edit or re-encoding occurred. `thumbnail-metadata-cleanup.json` records the hashes and `sanitize_png_metadata.mjs` in the reference-source folder performs this cleanup for future renders. Editable masters, models and embedded textures were not changed.

The sanitized editable master and portable generation/verification scripts are also included in [assets/reference-source](../../assets/reference-source/README.md). The master reopened through MCP, retained 19 collections and both packed maps, and passed all 19 saved-collection re-export comparisons. The complete comparison is recorded in `master-all-19-comparison.json`; `master-all-19-preservation.json` additionally confirms 19 byte-identical complete GLB binary chunks, JSON equality after only known name-prefix/history normalization, and unchanged original/release files and both masters. Earlier five-sample reports remain historical evidence. Full fresh-build equivalence and browser rendering are not implied.

These are unofficial reconstructions inspired by documented IKEA, LG, Samsung, Kohler, Daelim and hansgrohe products. They are not official CAD, manufacturer-endorsed assets, physical measurements or installation instructions. No manufacturer photos or extracted CAD were used as textures. Published overall dimensions are matched; bevels, seams, internal structures, material response, light output and some fixture installation details are authored estimates. The custom shower enclosure is not a hansgrohe product.

`manifest.json` records source URLs/SKUs, asset hashes, measured GLB bounds and per-model limitations; `validation.json` records independent binary geometry checks. All textures are embedded and locally procedural. `khronos-validation.json` records official glTF format validation, not visual equivalence or manufacturing safety.

Instances share immutable geometry/textures but clone materials and the node hierarchy. Only `TINT_` materials can be recoloured. Motion extras identify local rotation/translation axes and open amounts; fixed anchors are not animated. The outer editor group keeps unit scale; a child group applies `[requested W,H,D] / [reference W,H,D]`. Shared scenes retain legacy type IDs and 0.1mm dimension precision. Starting an explicitly empty scene remains empty after URL restoration.
